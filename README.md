# WhisperChat

Realtime-чат на WebSocket с комнатами по ссылке. Анонимный вход по отображаемому имени, история сообщений сохраняется в Postgres.

## Возможности

- Создание комнаты, подключение по ID
- Broadcast сообщений всем участникам комнаты в реальном времени
- Лимит участников комнаты, отклонение при превышении
- Уведомления о присоединении/отключении участников
- Асинхронное сохранение истории в Postgres, не блокирующее доставку сообщений
- Один зависший клиент не тормозит рассылку остальным

## Стек

- Go, `gorilla/websocket`
- PostgreSQL (`pgx`)
- Docker / Docker Compose


## Запуск

```bash
docker compose up --build
```

Поднимет приложение на `:8080` и Postgres. 
## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/rooms` | Создать комнату. Тело: `{"limit": 10}`. Возвращает `{"id": "..."}` |
| `GET` | `/rooms/{id}/history` | Последние сообщения комнаты |
| `GET` | `/rooms/{id}/ws?name=...` | Подключение к комнате по WebSocket |
